## 🔗 三、服务器（连接及线路测试）

1. 服务器远程连接工具（FinalShell）： [https://www.hostbuf.com/t/988.html](https://www.hostbuf.com/t/988.html)


1. 安装Curl
```
apt update && apt install -y curl
```


1. **可视化路由（NextTrace）安装命令**

```
curl nxtrace.org/nt | bash
```
