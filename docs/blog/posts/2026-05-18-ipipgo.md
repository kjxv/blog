### 📋 二、 极简检测 5 步曲（普通人秒懂的判定法）

#### 1️⃣ 第一步：Ping0 验明正身（辨别基本属性）

> 打开 [ping0.cc](https://ping0.cc)，重点核对 2 项：

* **🌍 国家/地区**：必须和你做的 TikTok 小店/目标市场 100% 一致。
* **🛡️ 网络类型**：必须绿色亮起 **`家庭宽带`**。（若显示 IDC、数据中心、机房，直接 ❌ 淘汰）。

#### 2️⃣ 第二步：Scamalytics 查欺诈与定性（网页密密麻麻的英文长文本直接忽略，往下滑只看两项硬指标！）

> 打开 [scamalytics.com](https://scamalytics.com) 输入 IP 查询：

* **📊 指标一：欺诈评分 (Fraud Score)**
* **🌟 顶级：** `0` 分（完美纯净，直接闭眼入）。
* **✅ 合格：** 小于 `20` 分。
* **❌ 报废：** 大于 `50` 分（绝对是脏 IP，直接让客服换号）。


* **🔍 指标二：连接类型 (Connection Type)**（在下方“操作员”表格的第五行）
* 🟢 **大绿灯（通过）：** 显示 `Residential`（住宅）、`DSL`、`Cable`（电缆）、`Corporate`（企业）。说明是实体线，安全！
* 🔴 **一票否决（淘汰）：** 显示 **`Hosting`（托管/机房）** ❌。说明是廉价低质货，必限流！
* 🟡 **特例（隐藏神仙卡）：** 显示 **`不适用 (N/A)`** 或者是 **`Unknown`**？别慌！只要你的**欺诈评分是 0**，且**第一步 Ping0 显示为家庭宽带**，说明这是厂商刚开出来的独立干净新线，用的人极少，在 TK 极易跑出爆款，直接通过！



#### 3️⃣ 第三步：AbuseIPDB 查犯罪案底（防垃圾二手 IP）

> 打开 [abuseipdb.com](https://www.abuseipdb.com) 输入 IP 查询：

* **🚫 举报记录 (Usage History)**：必须为 **`0%`**（或 0 次）。
* **⚠️ 判定：** 只要有近期被举报滥用、黑客扫描的记录，说明是被前人玩坏的黑历史 IP，拿来做电商必死号 ❌。

#### 4️⃣ 第四步：Whoer 查底裤（排查本地配置漏洞）

> **【🛑 防误判前置动作】**：测试前，**务必先将手机/电脑的时区改为 IP 当地时区**，并将浏览器首选语言添加为当地语言（如英语/德语）。

* 打开 [whoer.net](https://whoer.net) 检查：
* **Proxy / VPN** = `No`
* **WebRTC** = 绿色（绝对不能暴露国内真实 IP）。
* **伪装度评分** = 最好达到 `100%`（若扣分，根据提示对齐时区和语言）。



#### 5️⃣ 第五步：TikTok 官方实机终审（最终考核）

> 开启浏览器的 **`无痕/隐私模式`**（或用干净的手机环境），连上 IP 并打开 [tiktok.com](https://www.tiktok.com)。

* ❌ **节点报废：** 网页加载极慢、无限转圈，或者刷出的首屏视频、评论区全是无关边缘国家的语言（说明被 TK 识别为高风险代理，直接丢进垃圾流量池）。
* 👑 **完美合格：** 网页瞬间打开，且首屏视频、评论区、广告**全部是纯正的当地本土内容**。
