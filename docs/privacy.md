# 隐私政策

本页面说明小V博客及其个人数据工具“V 数据同步助手”在访问、统计和数据同步过程中涉及的信息处理方式。

## V 数据同步助手

V 数据同步助手是站点所有者自用的 YouTube 数据统计工具。它通过 Google OAuth 2.0，在账号所有者明确授权后访问其本人管理的 YouTube 频道数据。

### 访问的数据

根据用户授予的权限，本工具可能读取以下数据：

- YouTube 频道和视频的基本信息，例如视频 ID、标题、发布时间和公开状态；
- 视频公开统计数据，例如播放量、点赞数和评论数；
- YouTube Analytics 提供的频道及视频分析数据；
- YouTube Reporting API 生成的、已获授权账号的数据报告。

本工具不会读取用户的 Google 账号密码，也不会在未经用户授权的情况下访问其 YouTube 数据。

### 数据用途

上述数据仅用于：

- 统计本人 YouTube 频道和视频的运营表现；
- 记录视频发布后不同时间节点的数据；
- 将统计结果同步到本人管理的飞书多维表格；
- 支持本人进行数据对比、归档和运营分析。

本工具不会出售 Google 用户数据，不会将这些数据用于个性化广告，也不会向无关第三方共享。对 Google 用户数据的使用遵守 Google API 服务用户数据政策及其“有限使用”要求。

### 数据存储与安全

OAuth 授权文件、统计数据库和同步结果仅保存在用户本人控制的计算机、服务器及飞书多维表格中。访问凭据不会公开发布，也不会提交到公开代码仓库。

数据保留时间由用户根据统计需要决定。用户可以删除服务器、本地数据库或飞书表格中的相关记录。

### 撤销授权与删除数据

用户可以随时在 Google 账号的“第三方应用和服务”页面撤销 V 数据同步助手的访问权限。撤销后，本工具将无法继续读取新的 YouTube 数据。

如需彻底删除已保存的数据，用户可以同时删除本地或服务器中的 OAuth 授权文件、统计数据库以及飞书多维表格中的相关记录。

Google 及其合作伙伴可能会根据用户访问本站或其他网站的情况展示个性化或非个性化广告。用户可以通过 Google 的广告设置页面管理个性化广告偏好。
